# Security policy

Please report vulnerabilities privately, not in public issues: use this repository's "Report a vulnerability" button
(GitHub private vulnerability reporting, https://github.com/amitpatole/cgroupguard/security/advisories/new). Include the version, what you observed and how to reproduce it.
Do not include credentials, kubeconfigs or real cluster reports.

You can expect an acknowledgement within a few days. Fixes are released as soon as they are verified, and reporters are credited unless they prefer otherwise.
The trust boundaries and permissions are described in [docs/permissions.md](docs/permissions.md) and [docs/security.md](docs/security.md).
