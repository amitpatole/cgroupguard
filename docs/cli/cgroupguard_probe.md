## cgroupguard probe

Print local filesystem evidence as JSON (used inside probe pods)

```
cgroupguard probe [flags]
```

### Options

```
  -h, --help          help for probe
      --path string   Cgroup root to inspect (default "/sys/fs/cgroup")
```
